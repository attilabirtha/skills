# proClick Branding

Apply the existing proClick identity faithfully across formats. This skill governs the shared brand system; it does not turn every deliverable into a sales deck or commercial offer.

## Start with the artifact

Identify the audience, language, medium, and supplied references. The user's explicit direction and an approved client/template asset take precedence. Otherwise choose one visual mode and keep it consistent:

- `presentation` for branded decks and general collateral;
- `offer` only when the work intentionally matches the commercial-offer system;
- `web` when matching proclick.ro or a supplied web reference.

Do not blend nearby coral, paper, or ink values across modes. Read [the identity system](references/identity-system.md) for precise brand decisions and use [brand tokens](assets/brand-tokens.json) for exact values.

## Assets

Use the bundled raster wordmarks; never redraw or generate the proClick logo.

- `assets/proclick_logo.png` is for light or warm-paper surfaces.
- `assets/proclick_logo_white.png` is for charcoal or sufficiently dark photography.
- `assets/proclick_team_wide.jpg` is the default landscape team image.
- `assets/proclick_team_cover_full.png` is a portrait full-team composition.
- `assets/originals/` contains the supplied master logo formats: Illustrator (`.ai`), SVG, PDF, and PNG variants. Read its manifest before selecting a source file.

Preserve logo and photo aspect ratios. Keep headline copy clear of faces and do not crop teammates out to force a layout.

Prefer an original SVG for a scalable web or design target when the target supports it. Keep Illustrator and PDF originals unchanged; use the standard PNGs when the output pipeline needs a verified raster asset.

## Working rules

1. Write the brand as `proClick` in prose. Preserve the user's language and meaningful diacritics.
2. Use direct, concrete writing: name the work, owner, result or decision. Distinguish evidence, targets, examples, and proposed capabilities.
3. Use coral sparingly for emphasis, near-black for body copy, and charcoal for an intentional strategy/section shift. Pale green is a recommendation surface, not decorative filler.
4. Keep the selected artifact editable where possible: use real text, tables, charts, and color values rather than baking a whole layout into an image.
5. Do not reuse old metrics, client logos, partner badges, testimonials, pricing, or claims without current authorization and source evidence.
6. Keep commercial categories clear wherever they appear: separate one-time work, recurring services, media spend, and platform usage. State currency, tax basis, period, and payer only when those amounts are part of the brief.

## Route specialized work

- Use `proclick-presentation` for an editable presentation, pitch deck, case study, or briefing. It owns slide-specific layouts and authoring validation.
- Use `proclick-price-offer` for a standalone commercial offer PDF, payment schedule, commercial appendix, or client-specific pricing proposal.
- Use this skill for shared identity decisions and branded assets across other artifact types, or alongside either specialized skill when the work needs their format-specific workflow.

## Review

Before delivery, check wordmark fidelity and contrast, selected-mode consistency, readable type, photo framing, language/glyph support, and factual provenance. Keep the company's legal contact information limited to artifacts that need it; verify it before issuing legal or commercial material.
